# Isoterma · web de muestra

Web de **Isoterma**, empresa de aire acondicionado con bomba de calor, calefacción y aerotermia en Valencia (tres socios · 624 931 947).

**Online:** https://nocodya-hue.github.io/isoterma/

- Web estática de una página: hero con vídeo que cambia entre invierno y verano según el mes (o con `?estacion=invierno` / `?estacion=verano`), garantías, servicios con precio de partida, comparativa de calefacción, paso a paso, calculadora de presupuesto que envía el resultado por WhatsApp, preguntas frecuentes y contacto.
- Los precios de la calculadora están en `js/precios.js`.

**Es una web de muestra.** Fotos y vídeos generados con IA (personas ficticias). Precios orientativos, garantías y compromisos de servicio pendientes de confirmar por la empresa. Faltan aviso legal, privacidad, cookies, NIF y dominio.
